# 🎛️ AE Migration Tool

Перенос пользовательских файлов между версиями **Adobe After Effects** с просмотром изменений, резервным копированием и откатом.

> **AE Migration Tool** помогает перенести скрипты, плагины, пресеты и другие пользовательские файлы из одной версии **After Effects** в другую. Перед копированием приложение сравнивает файлы, показывает план и сохраняет данные для возможного отката.

## ✨ Возможности

| | |
|---|---|
| 🔎 **Поиск установок** | Обнаружение After Effects через систему и добавление папок вручную. |
| 📂 **Выбор путей** | Выберите исходную и целевую установки или укажите папки через диалог выбора. |
| 🧾 **План до запуска** | Сканирование с SHA-256 и предварительный просмотр найденных файлов и конфликтов. |
| 🧩 **Категории файлов** | Скрипты, ScriptUI Panels, плагины, CEP-расширения, пресеты, рабочие пространства, настройки и другие файлы. |
| 🛡️ **Решение конфликтов** | Оставить целевой файл, заменить его копией из источника или сохранить резервную копию целевого файла. |
| ↩️ **Откат** | Восстановление заменённых файлов и удаление файлов, добавленных миграцией. Отметка об откате сохраняется между запусками. |
| 🗂️ **История** | Список миграций и связанные с ними данные резервного копирования. |
| 🌗 **Темы** | Светлая и тёмная тема интерфейса. |

<a id="requirements"></a>

## 📋 Требования

- Windows 10 или новее, x64.
- Adobe After Effects с доступными папками установки, которые нужно просканировать.
- Для разработки: Node.js LTS, Rust stable для MSVC и Microsoft C++ Build Tools.
- Приложение запрашивает права администратора при запуске, чтобы записывать файлы в защищённые папки установки.
- Для отображения интерфейса используется Microsoft Edge WebView2. Установщик включает bootstrapper WebView2; если Runtime ещё не установлен, для его установки может потребоваться подключение к интернету.

См. [системные требования Tauri для Windows](https://v2.tauri.app/start/prerequisites/) и [настройки Windows-установщика](https://v2.tauri.app/distribute/windows-installer/).

<a id="quick-start"></a>

## 🚀 Быстрый старт

1. Откройте вкладку **Releases** этого репозитория.
2. Скачайте `AE Migration Tool_<версия>_x64-setup.exe`.
3. Запустите установщик и пройдите шаги установки.
4. Откройте AE Migration Tool и подтвердите запрос Windows на запуск от имени администратора.
5. Выберите исходную и целевую версии After Effects.

**Запуск без установки:** скачайте `AE Migration Tool_<версия>_x64-portable.zip`, распакуйте архив и запустите `AE Migration Tool.exe`. Для portable-версии WebView2 Runtime должен быть уже установлен.

<a id="workflow"></a>

## 🔄 Как пользоваться

1. На странице **Миграция** выберите источник и цель. Установки можно выбрать из списка или добавить по пути.
2. Запустите сканирование и проверьте найденные файлы и различия.
3. Выберите действия для конфликтующих файлов. Перед заменой исходный целевой файл сохраняется в резервную копию. Для варианта «Сохранить целевой» резервную копию можно включить отдельно.
4. Запустите миграцию. Приложение не удаляет файлы, присутствующие только в целевой установке.
5. Чтобы вернуть прежнее состояние, откройте **Историю** и нажмите **Откатить** у нужной миграции.

### Где находятся данные

- Папка резервных копий по умолчанию: `AE-Migration-Tool-Backups` на уровень выше выбранной целевой папки.
- История миграций: `%LOCALAPPDATA%\AE-Migration-Tool`.
- Для каждого запуска миграции резервные записи связаны с её идентификатором.

<a id="safety"></a>

## 🛡️ Безопасность данных

- До запуска миграции можно проверить предварительный план.
- Совпадающие файлы определяются по SHA-256.
- Резервные копии создаются до перезаписи целевых файлов.
- Новые файлы также учитываются, чтобы откат мог удалить их.
- Откат восстанавливает исходные файлы из резервной копии; удаляются только файлы, созданные данной миграцией.
- Файлы, присутствующие только в целевой версии, сохраняются.
- Сканер пропускает известные временные данные After Effects и некоторые бинарные файлы. Перед запуском проверьте список в плане миграции.

<a id="build"></a>

## 🧰 Сборка из исходников

### Подготовка

Установите Node.js LTS, Rust с MSVC toolchain, Microsoft C++ Build Tools с компонентом **Desktop development with C++** и WebView2 Runtime. Для деталей см. [документацию Tauri](https://v2.tauri.app/start/prerequisites/).

### Разработка

```powershell
npm ci
npm run tauri -- dev
```

### Установщик NSIS

```powershell
npm ci
npm run tauri -- build --bundles nsis
```

Готовый установщик появится в:

```text
target/release/bundle/nsis/AE Migration Tool_<версия>_x64-setup.exe
```

### Проверки ядра

```powershell
cargo test -p aem-core
```

<a id="cli"></a>

## ⌨️ CLI

В репозитории есть экспериментальный CLI для диагностики и пакетной работы. Основные команды:

```powershell
cargo run -p aem-cli -- detect
cargo run -p aem-cli -- scan "C:\AE\2025\Support Files" --json
cargo run -p aem-cli -- plan "C:\AE\2025" "C:\AE\2026" --json
cargo run -p aem-cli -- execute "C:\AE\2025" "C:\AE\2026" --backup "C:\AE-Backups"
cargo run -p aem-cli -- rollback "ЗАМЕНИТЬ_НА_MIGRATION_ID" --backup "C:\AE-Backups"
cargo run -p aem-cli -- list-backups "C:\AE-Backups"
```

Для интерактивной проверки плана, истории и отката используйте графическое приложение.

<a id="troubleshooting"></a>

## 🩺 Решение проблем

| Симптом | Что проверить |
|---|---|
| Установка не найдена | Добавьте папку After Effects вручную на странице **Версии**. Укажите каталог установки, а не отдельный файл. |
| Установщик не открывает приложение | Проверьте, установлен ли WebView2 Runtime. Установщику может понадобиться интернет для его установки. |
| Windows показывает запрос UAC | Это ожидаемо: приложению нужны права для записи в защищённые папки After Effects. |
| Откат недоступен | Проверьте, что в папке резервных копий сохранился `backup_index.json` и файлы конкретной миграции. |
| Недостаточно прав или отказано в доступе | Запустите приложение и подтвердите запрос администратора; закройте After Effects на время миграции. |
